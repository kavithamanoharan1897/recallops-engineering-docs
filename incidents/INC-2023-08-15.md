# Incident Report: Database Connection Timeout (INC-2023-08-15)

## Status
Resolved

## Summary
On August 15, 2023, the production environment experienced intermittent database connection timeouts for approximately 45 minutes.

## Root Cause
The connection pool size was set too low for the increased traffic following a marketing campaign. The pool became exhausted, leading to timeouts.

## Resolution
Increased the maximum connection pool size from 20 to 100 in the application configuration.

## Key Learnings
- Always monitor connection pool usage.
- Scale connection pools ahead of known traffic spikes.
- Implement better circuit breakers for database failures.
