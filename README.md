# RecallOps Engineering Knowledge Base

This repository serves as the "Institutional Memory" for the RecallOps AI agent. It contains structured engineering documentation, including incidents, deployment notes, KT sessions, and debugging learnings.

## 📂 Structure
- `incidents/`: Post-mortem reports and root cause analyses.
- `deployments/`: Summaries of major releases and environment changes.
- `kt-sessions/`: Notes and resources from internal Knowledge Transfer sessions.
- `playbooks/`: Step-by-step guides for operational tasks.
- `debugging/`: Deep-dives into obscure bugs and technical learnings.

## ✍️ Contribution Guidelines
- Use Markdown format for all documents.
- Include a `# Title` as the first line.
- Always add relevant `#tags` at the end of the document to help the AI index the content.
- Be technical, concise, and provide actionable insights.
