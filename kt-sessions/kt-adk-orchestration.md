# KT Session: Understanding ADK-Style Orchestration

## Date
2024-01-10

## Presenter
Alex (Lead Engineer)

## Summary
This session covered the principles of Agentic Design Kit (ADK) style orchestration. 

## Key Points
- **Decoupled Reasoning:** Separate the "reasoner" (LLM) from the "executors" (tools/actions).
- **Goal-Oriented Planning:** The agent should first create a plan before executing actions.
- **Feedback Loops:** Use the output of actions to refine the plan.
- **State Management:** Maintaining a session-long state for complex multi-turn tasks.
